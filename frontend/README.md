# PCOSense – Frontend

The React 19 and Vite frontend interface for **PCOSense**, an ML-powered PCOS risk screening web application.

## Overview

- **Framework:** React 19 (`react ^19.2.8`)
- **Build Tool:** Vite (`vite ^8.3.1`)
- **Icons:** `lucide-react`
- **Linting:** Oxlint (`oxlint ^1.81.0`)
- **Styling:** Custom responsive CSS using CSS design tokens, healthcare palette, and accessible form controls.

## Available Scripts

In the `frontend` directory:

- `npm run dev`: Starts the local development server (default `http://localhost:5173`).
- `npm run build`: Bundles the production build to `dist/`.
- `npm run lint`: Runs Oxlint static code analysis.
- `npm run preview`: Previews the local production build.
